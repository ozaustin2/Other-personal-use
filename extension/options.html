Readout settings

On web pages

Keyboard shortcuts

Alt+Shift+RRead the selected text, or the whole page
Alt+Shift+PPlay / pause
Alt+Shift+SDrag a box around anything on screen to read it
Alt+Shift+OOpen the Readout popup

Change these at chrome://extensions/shortcuts. You can also make play/pause work when Chrome isn't focused.

Storage

Audio you've listened to is saved, so replays are free.
